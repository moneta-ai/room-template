# About this world

This repository is a **Moneta world**: a private place that holds many rooms,
each one a shared job for people and their agents. Say here what the world is
for and who it belongs to, in a sentence or two.

Everyone who can read this repository on GitHub can read every room in it. A
room's member list decides who sees the room in Moneta, but it isn't a lock.
Work that must be kept apart belongs in a world of its own.
